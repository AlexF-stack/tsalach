# TSALACH S.A.

Site corporate Next.js pour **TSALACH S.A.** (Libreville, Gabon) — structuration, financement, construction, infrastructures et PPP.

## Stack

- Next.js 15 (App Router)
- React 19 + Tailwind CSS 4
- Framer Motion
- i18n EN / FR

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) (redirige vers `/en`).

## Contenu

Aligné sur la présentation institutionnelle TSALACH et l’en-tête officiel (contacts Libreville).

## Domaine

Configurer `NEXT_PUBLIC_SITE_URL` (voir `.env.example`).
